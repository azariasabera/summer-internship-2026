# `tea.features`

Single source of truth for feature construction.

Used by:

- confidence estimation
- child-speech probe
- feature-fusion experiments

## Feature groups

- MTKD softmax + derived (entropy, margin, max-prob)
- Acoustic (RMS, F0, voiced ratio)
- Text sentiment (FI / EN) + speech rate
- Optional pooled embeddings (768-d)
